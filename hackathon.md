Build agents that act, not ones that just answer.

Agents That Act: TrueFoundry × Polaris Hackathon is a one-day hackathon built around TrueForge, TrueFoundry's open-source agent harness. The challenge is to build an AI agent that can reach real systems, run the code it writes safely, and know when to stop and ask.

With a ₹3,00,000 prize pool, AWS and OpenAI credits for shortlisted teams, and mentors from TrueFoundry and Polaris, this is an opportunity to build and showcase an agent that does something real.
THE CHALLENGE

Build an agent for a real-world job that is genuinely worth handing over to AI.

Your agent should:

    Reach a real system such as a database, repository, cloud account, or ticket queue.
    Run the code it generates safely inside a sandbox.
    Stop before irreversible actions and wait for human approval.

You can build for any domain. Suggested ideas include cloud cost cleanup, database migration, release management, support ticket resolution, access review, and infrastructure runbooks.
HACKATHON HIGHLIGHTS

    Build with TrueForge, an open-source MIT-licensed agent harness.
    Get access to AWS and OpenAI credits for shortlisted teams.
    Learn from and interact with TrueFoundry and Polaris mentors.
    Showcase your working agent to the judging panel.
    Food, power, and Wi-Fi are provided at the venue.

GET STARTED WITH TRUEFORGE

TrueForge is open source, MIT-licensed, and runs locally with one command:

npx @truefoundry/trueforge
